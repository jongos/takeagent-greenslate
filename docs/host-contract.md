# Host integration contract

This package is a development adapter, not an authenticated service. `integration-manifest.json` may describe development availability in TakeAgent; `liveEnabled` must remain false until the gates are met.

Call `previewCsv(buffer, metadata, access, now)` from `src/files.js`. For XLSX, hosts MUST use `await previewXlsxIsolated(buffer, metadata, access, {sheetName, now})` from `src/isolated-xlsx.js`; never call the raw `previewXlsx` or `readXlsxTable` parser on the host thread. For JSON use `preview` from `src/adapter.js`. `metadata` is the fixture object without `rows`; the parser supplies rows and source-row positions. Supply the explicit mapping, source totals, currency, as-of date, revision, project and accounting bases. The host must never derive trusted access from submitted metadata. Resolve access from authenticated account/project ownership on each request and revision comparison, check billing and revocation, and authorize source-project mapping before parsing.

Use a strict allowlist of the supported fixture metadata keys. Keep raw upload bytes only for the approved retention interval, in tenant/project-scoped storage. Prevent cross-project reuse by validating the immutable source project mapping. Do not log files, parsed rows or raw parser exceptions. Catch errors and return a redacted validation failure. The XLSX entry runs a fixed worker with 64 MiB old-generation heap, 16 MiB young-generation heap, 4 MiB stack, a hard 5-second wall-clock deadline and a 4 MiB response cap. Input bytes are capped at 2 MiB and metadata at 256 KiB before worker creation; response size is checked in both worker and receiver. Timeouts, worker errors, premature exit, malformed responses and response overflow fail closed with redacted errors, and termination completes before the promise settles. Hosts may lower time/response caps but cannot raise them. Resource limits cover V8 heap, not all native allocations, ArrayBuffers or process RSS; CPU is bounded by wall time, not a CPU quota. This is not an OS security sandbox. Production untrusted uploads still require deployment-level process/container memory and CPU limits, concurrency limits and request cancellation.

Output has integer minor-unit amounts, separate cost fields, source row numbers, provenance, import timestamp, warnings and a stable fingerprint. CSV source rows are physical end-line numbers for multiline records; XLSX source rows are worksheet rows. Unselected workbook sheets are not emitted, but the XLSX library parses the workbook internally, so minimize uploads to a selected-only workbook before transmission. Hidden sheets and selected hidden rows/columns are rejected. Parent/header records must be excluded explicitly. No formulas or macros run and formula cells are rejected, even with cached values. Do not transform formatting-only numeric account codes: identifiers must be strings.

Show a transmission/mapping preview and source totals; do not write to finance plans, committed funding or accounting services. Bind any future apply consent to account/project, fingerprint and revision, recheck version at apply, and make duplicate fingerprints idempotent within the project. The present library has no apply method or database. `compare` expects previously validated snapshots from trusted storage, not arbitrary client JSON. Redact/escape source strings in UI, including account codes; they are untrusted data. Cost changes may prompt review, but are not proof of funding gaps or cash timing without separate finance-plan evidence.

On disconnect, revoke source credentials if introduced, stop jobs and delete stored files/snapshots according to policy. This stateless package cannot implement host deletion, authorization or billing. No data is retained by the package itself.

## Snapshot identity and provenance

Canonical `complete` participates in the fingerprint; changing it under the same revision is rejected. CSV/XLSX readers derive allowlisted `source` fields and override submitted source claims: `format`, `sha256` of input bytes, `headerRow`, one-based `columns`, and XLSX `sheetName`. Rows retain source-row coordinates; unselected sheet contents are not returned. Direct JSON source claims are not independently verified file provenance; derive or validate these in the host. Bind consent to evidence identity, establish a reviewed baseline for older fingerprints, and display rejected unsafe revision deltas rather than rounding them.
